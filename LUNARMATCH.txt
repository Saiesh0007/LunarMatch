=== Implementation ===

Feature Extraction
- RIFT2: Phase-congruency descriptor with 216-D features
- Multi-scale phase-congruency pyramid
- HOPC: Higher-order power spectrum structural descriptor (288-D)
- MAGSAC++: Threshold-free robust estimation
- Sub-pixel phase-correlation refinement
- Sensor-pair adaptive routing (OHRC / TMC-2 / IIRS / LRO NAC / SELENE)
- Uniform Spatial Grid Balancing (6x6 grid, coverage metrics)
- PDS4 and GeoTIFF readers
- Registration failure thresholds
- Demo router: /api/demo prefix with clean endpoint wiring
- Infinity/NaN sanitization in JSON serialization
- Crash guard: pipeline returns NOT_RELIABLE instead of crashing

Measured Results (Demo Pair A)
- SIFT: 1393 inliers, RMSE 0.461px — ACCEPTED
- RIFT2: 21 inliers, RMSE 0.704px — NOT_RELIABLE on smooth synthetic terrain

Known Limitation
- On smooth synthetic demo pairs (seed 26166), SIFT's gradient-based features
  outperform RIFT2's phase-congruency features. RIFT2 is designed for real
  lunar imagery with strong Sun-angle variation where SIFT's gradients reverse.
  Robustness sweep shows RIFT2 has lower per-match RMSE at all illumination deltas.
