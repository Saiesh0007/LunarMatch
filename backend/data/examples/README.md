# Demo Data Provenance

The bundled demo images are local prototype assets and are not claimed to be Chandrayaan-2 PRADAN data.

- Source: synthetic/local prototype imagery
- Reason bundled: public mission-data access and licensing are not part of this repository
- Purpose: demonstrate illumination and registration diagnostics

## Pair B: OHRC/TMC-2 proxy demo
- Source: synthetic/local prototype imagery
- Reason bundled: no real Chandrayaan-2 pair is bundled
- Purpose: demonstrate scale-invariant routing and failure-safe artifacts
